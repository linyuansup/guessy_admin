# Flutter App Specification

## 1. Project Overview
- **Project name**: guessy_admin
- **Core functionality**: A simple app with three pages (Questions, Rounds, Controls) accessible via bottom navigation tabs

## 2. Technology Stack & Choices
- Flutter 3.x with Dart
- Material Design 3
- StatefulWidget with IndexedStack for tab persistence
- No external dependencies required (using built-in Flutter components)

## 3. Feature List
- Bottom navigation bar with 3 tabs
- Three pages: 问题 (Questions), 回合 (Rounds), 控制 (Controls)
- Tab state preservation when switching
- Visual indicator for selected tab

## 4. UI/UX Design Direction
- Clean, minimalist Material Design 3 interface
- Bottom navigation bar at the bottom of the screen
- Each page displays its title prominently
- Default Flutter color scheme with primary blue accent
